# Vision

clankerhands is the hands to the brains of an agent.

It is a service that runs on a machine, such as a clankerbox but not necessarily one. It provides tools over MCP that an agent uses to do all the things it would normally need to do.

## Open

The exact shape of the tools still needs research: how tools look in Pi, Codex, Claude Code, Amp and others, for inspiration.
